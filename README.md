# Deck Manager

Deck Manager is an application that gathers and helps with all the tasks
associated with managing the deck of officials at a large swim meet — from
sign-ups and check-in, through building session rosters and
auto-assignment, to print-ready deck assignment PDFs. For the purposes of
this application, a meet is considered large if it requires a dedicated CJ
(Chief Judge) team. Deck Manager is aimed at the **Team Lead CJ**.

This repository hosts releases for Deck Manager: installers and
documentation for each version.

---

## Getting Started

**1. Download and install**
Grab the installer for your platform from the
[Latest Release](https://github.com/mabnhdev/deck-manager-releases/releases/latest)
page (`DeckManagerSetup-x.x.x.exe` for Windows, or for macOS
`DeckManager-x.x.x.dmg` for Apple Silicon / `DeckManager-x.x.x-x86_64.dmg`
for Intel — not sure which you have? Apple menu → About This Mac → "Chip"
means Apple Silicon, "Processor" means Intel), and see the **Installation
Guide** attached to that release for step-by-step setup instructions.

**2. Take the Quick-Start walkthrough**
Once installed, open the **Quick-Start** guide (also attached to the
release) for a short, hands-on walkthrough of setting up your first meet.

**3. Go deeper with the User Manual**
For complete, section-by-section documentation of every tab and feature,
see the full **Deck Manager User Manual**, attached to the same release.
